About this project

Learning by building.

I’m Nathan Lam. This website is part of my CSCE 412 cloud computing coursework.

The purpose

This project explores the decisions behind a secure static website: where its files live, how visitors reach them, and which systems control access.

The approach

Keep the website simple and make the infrastructure understandable. Each page uses HTML, shared CSS, and browser-side JavaScript without a continuously running backend.

Next steps

The broader assignment includes a custom multi-agent system, recorded deployment checks, and a controlled failure-and-recovery demonstration. This site does not claim those tasks have been completed.
